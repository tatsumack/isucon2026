## ボトルネック上位
### 1. 画像の配信の権限確認 (DB)
- 根拠: slow.txt の1位。13,831回、平均 2.97ms、DB 時間の23.5%
- 原因箇所: `go/image_api.go:66` 付近 (`FROM image_objects i JOIN users u ...`)。image_objects を id だけで引くと、今回直したクエリと同じく全パーティションを引く可能性がある (未確認)
- 対策案: EXPLAIN で、パーティションを全部引いているかを確かめる。引いていれば、投稿の画像は posts.image_id から引くなど、image_objects を id だけで探さないようにする
- 期待効果: 中 (推測)。DB の空きが増える
- リスク: 権限確認の結果を変えないこと (プロフィール画像・RealMoji の画像も対象)

### 2. asia1 の iowait
- 根拠: wa 7.1% → 17.0%、idle 69.5 → 54.9。ディスクの読み込み量は同じ
- 対策案: pidstat -d の時系列と、エクスポートや画像の配信の時刻を突き合わせる
- 期待効果: 不明
