## 設定の判定 (split 16 / 8 / 16 と adaptive)

- **投稿した割合 (最後の期間 0.49) は、adaptive と同じ。** その他の枠を 8 → 16 にした分で、#34626 の 0.37 から上がった
- **最後の期間の完了率は、adaptive のほうが高かった** (asia 98% / europe 99%。split は 93% / 91%)。約 +1,700点
- score の差 (+4.6%) は、人数の違い (5日目が asia +6%、europe +16%) で説明でき、**split が adaptive より良いとは言えない**
- 現在の main は split (16 / 8 / 16、画像 critical)。adaptive にするなら、`etc/env/asia1.sh` の `ISUREAL_PRIORITY_SCOPE` を `adaptive` にする1行の変更。**この変更は、リージョンごとの人数が揃った条件で、もう1回比べないと決められない**
