- ブランチ: `perf/image-read-cache` (`6f3d67d`) = main (`0411db9`、#57 を含む) + 画像キャッシュの変更 + `bench-capture.sh` の `pidstat -d` (PR #53)。4台にデプロイ
- 計測: 06:18:36 UTC からの150秒 (4台、asia1 / europe1 `061836`、america1 `061837`、asia2 `061838`)
- 結果: **score 109522**。基準の #20663 (main + #57、105922) から **+3.4%**。ベンチ1回ずつの比較なので、ぶれを含む
- 計測の失敗は無い

## 次の候補 (未検証)

- キャッシュの上限を上げる (256MB → 512MB など)。前日の画像まで残せば、残りの読み込みも減らせる可能性がある
  - asia1 のメモリは 3.8GB。isureal の RSS は計測後 792MB、AnonPages 1.2GB。Go の GC は生きているデータの約2倍までヒープを伸ばすので、上限を 256MB 上げると RSS は最大 500MB 程度増えうる。GOMEMLIMIT と合わせて考える
