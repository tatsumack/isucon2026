## ボトルネック上位

### 1. asia1 の CPU (sy が高い)
- 根拠: 負荷の山で idle 9.3%、sy 37.4%。pprof flat の1位は `Syscall6` 29.1% (#17256 は 26.9% 前後)、`memclrNoHeapPointers` 8.3%
- asia の人数が早く増えると、asia1 に処理が集中し、europe / america から転送された API も遅くなる
- 対策案: asia1 から処理を外す。europe1 / america1 は idle 約85〜90% で空いている。たとえば europe / america のユーザーの feeds / memories を asia1 に転送せず、手元で処理する (DB との往復が増える代わりに asia1 が空く)。syscall の内訳 (ソケットか、ファイルか) を `-peek` で確かめてから決める
- 期待効果: 大 (europe / america の人数の伸びに直結すると考えられる)

### 2. ディスク
- 書き込みは減り、iowait も下がった。今回の計測では、ディスクの待ち時間 (約3ms) は小さく、主なボトルネックではない
- 読み込みは処理量に比例して増えている (62MB/s)。初期画像の読み込み (export、画像の取得)
