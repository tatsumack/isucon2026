## ボトルネック上位

### 1. 画像の閲覧権限の確認クエリ (DB) — PR #48 の対象
- 根拠: `SELECT u.secret_key_hash, i.media_type, (...)` が 13,658回、平均 2.08ms、合計 28.4秒、DB 時間の 11.8% (#26719: 13,216回 / 2.25ms / 15.2%)
- 原因箇所: `go/image_api.go` の閲覧権限クエリ (36個のパーティションを全部探索する。PR #48 の説明を参照)
- 対策案: PR #48 (`image_owners`) をマージする。asia2 の idle 5% 未満が 23秒あるので、DB に余裕を戻す意味がある
- 期待効果: 中。クエリが 2.08ms → 0.2ms 程度になれば、DB 時間で約 25秒 (150秒の計測のうち) 減る見込み (推測)

### 2. ユーザー検索 (DB)
- 根拠: `SELECT id, username, ... FROM users WHERE status=$5 AND id<>$1 AND (...)` が 3,046回、平均 **11.63ms**、合計 35.4秒、DB 時間の **14.8% (最大)**。#26719 は 3,386回 / 7.07ms / 12.3%
- 原因箇所: `go/user_read_api.go` の検索クエリ
- 対策案: `sql/005-user-search-trgm.sql` (pg_trgm) は main に入っているのに、平均が 7.07ms → 11.63ms に伸びている。実行計画 (`EXPLAIN`) で、GIN インデックスが使われているかを確認する
- 期待効果: 中。検索は 1件 2点で、友達申請の流れの入口
- リスク: `/initialize` のあとも、インデックスが保たれていること

### 3. export のクエリ (DB)
- 根拠: `SELECT p.id, p.author_id, ..., w.ended_at AS window_ended_at FROM posts p JOIN ...` が 206回、平均 **149.89ms**、合計 30.9秒、DB 時間の 12.9% (#26719: 200回 / 112.27ms / 11.5%)。asia1 の `GET /api/me/export` は 97回 / 平均 2.126s (#26719: 106回 / 1.580s)
- 原因箇所: `go/export_api.go`
- 対策案: クエリの実行計画を確認する (1回に約148行を返している)。export は 1件 20点
- 期待効果: 中

### 4. 友達フィードのクエリ (DB)
- 根拠: `WITH me AS (...), friends AS (...)` が 16,288回、平均 1.65ms、合計 26.9秒、DB 時間の 11.2% (#26719: 14,945回 / 1.36ms / 10.4%)
- 原因箇所: `go/post.go:118`
- 対策案: 友達の一覧をプロセス内に持つ。無効化は、友達の追加・削除・ブロックの書き込み
- 期待効果: 小〜中

### 5. asia1 の「その他」の枠の待ち
- 根拠: asia1 の `GET /api/images/:id` 1.562s、`POST /api/friend-requests` 1.649s、`GET /api/me/export` 2.126s (いずれも #26719 より長い)。`POST /api/posts` は 0.152s で変わらない。asia1 の idle 5% 未満は 7秒
- 原因箇所: `go/priority.go` (asia1 の優先制御。投稿の経路 / 重い API / その他の枠)
- 画像の署名は、すでに main に入っている PR #49 (期限を時間単位に切り捨てて署名を使い回す) と PR #50 (署名の計算を europe1 / america1 へ移す) で、asia1 の CPU の 65% (#13634) → **10.8%** (`computeImageSignature` 5.06s / 47.01s) まで減っている。残りは、投稿の応答の画像署名 (`signedImageURL` 9.8%) で、PR #64 (`perf/post-signature-remote`、OPEN) が対象
- 対策案: 枠の割り当ての見直しは、別の施策として扱う。PR #64 は、取り込めば asia1 の CPU が最大 約10%減る見込み (推測)
- 期待効果: 中
